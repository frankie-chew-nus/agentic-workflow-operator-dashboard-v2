## Preservation method

These Markdown files were exported from the MSI5002 Project's indexed source text. Text and headings were retained, but the GitHub copies are **not certified byte-identical** to the local originals because indexing/export may normalize formatting or line endings. The manifest records the Git blob SHA of each uploaded text export. The original source files remain available in the Project and in the previously prepared local ZIP package.

Do not replace original source evidence with these exports when exact-byte authenticity matters. Do not treat written rules or paper PASS as executable production proof.
