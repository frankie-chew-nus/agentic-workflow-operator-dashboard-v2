# Main Finding

W6.2 v1 produced a clear route for all synthetic cases tested.

No paper walkthrough required a change to W6.2 v1.

One implementation finding was recorded from **T09**:

> The Candidate Acceptance Checklist can return PASS while the separate Field 8 aggregate limit still requires HOLD. A future automated implementation must therefore check both the candidate-level acceptance result and the research-commission release count before permitting B→C transfer.

This does not require a W6.2 v2 at the paper-rule level because Field 8 already provides the required stopping rule.
